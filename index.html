Approximately 95% of the code in this project has been vibe coded, or some may say AI-assisted development.

AI tools are used throughout development to generate, troubleshoot, explain, refactor, and document code as the project evolves.

Purpose of the Project

The purpose of this project is to demonstrate course concepts by designing and implementing a playable game with useful, readable, and interactive user-interface systems.

Development focuses on learning through hands-on work with Unity, C#, UI/UX design, world-space interfaces, HUD systems, inventory interaction, menus, and the supporting gameplay systems those interfaces depend on.

AI assistance is used as a learning and development tool throughout the project, allowing game-development concepts and systems to be explored, implemented, and understood through hands-on work.

Current Project

The game is currently an FPS / survival-style open-world prototype inspired by RPG and adventure games. The project emphasizes UI systems that remain useful and intuitive for players with different experience levels.

Current UI systems include the inventory grid, inventory hotbar, item tooltip, floating interaction text, enemy health bar, ammo counter and reload feedback, radial menu, menu hint, no-ammo alert, player health bar, and player stamina bar.
