October 23, 2026 HUD, inventory, and interaction UI expansion
Added Inventory Hotbar

An eight-slot hotbar was added to expose quick-access inventory slots directly on the gameplay HUD.

The selected hotbar slot can be changed with number keys, allowing commonly used items to remain visible without opening the full inventory.

Added Item Tooltip Hover

Hovering over an inventory item now displays a temporary tooltip containing item information such as the item name, type, description, and quantity.

The tooltip behaves as an overlay so the information appears only while the player is inspecting an item.

Added Player Health and Stamina Displays

Player health and stamina were added as persistent HUD elements so important status information remains visible during gameplay.

Added Menu Hint and No-Ammo Alert

A menu input hint was added to show the player how to open the radial menu.

A no-ammo warning was added to provide immediate feedback when the player attempts to fire without usable ammunition.

Added Floating Interaction Text

World-space interaction text was added near interactable objects so players can identify items and understand available actions while remaining in the game world.

TextMeshPro material presets allow the interaction text to use white lettering with a black outline without changing unrelated UI text.

Made the Inventory Key Configurable

The inventory toggle was changed from a hard-coded Tab key to an Inspector-configurable KeyCode field.

This allows keys such as Tab, I, or B to be selected without editing the InventoryManager script.

October 8, 2026 Initial gameplay UI systems
Implemented the Inventory UI

A grid-based inventory was implemented to display and manage collected items.

The inventory supports item slots and drag-and-drop movement between slots.

Implemented the Enemy Health Bar

A world-space health bar was implemented above the enemy target so health information remains associated with the object in the game world.

Implemented the Ammo Counter and Reloading UI

The weapon system tracks ammunition and reloading while the HUD displays the current ammo state to the player.

Implemented the Radial Menu

A circular menu was implemented to organize multiple interface choices around a central point while keeping the game world visible in the background.

September 2, 2026 Initial project proposal and UI direction
Established the RPG + Adventure Game Concept

The initial proposal defined the project as an RPG / adventure game built to demonstrate course knowledge through practical UI and GUI implementation.

The planned scope was a one-semester small open-world game intended to combine UI experimentation with enjoyable gameplay.

Defined the Initial UI Goals

The proposal identified character-sheet UI, dialogue UI, and open-world map interfaces as major target features.

The project also established a broader goal of investigating how game UI can be made useful and intuitive for players with different experience levels.

Defined the Original Technology Plan

The original proposal listed Godot, C++, GitHub, public asset libraries, and Firebase as the intended technology stack.

The implementation later moved to Unity and C#. Firebase remains a possible future direction for web or online data features.

Established a Two-Week Development Cycle

Development milestones were planned around roughly two-week periods covering the game world, player controls, interactable objects, informational UI, and later integration and polish.
